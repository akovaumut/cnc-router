A CNC Router planned, designed and planned to be assembled all by me. Creating a project to have fun and learn. The machine is designed to cut soft Aluminum Alloys(like 6061) and wood.

Specs:
 - 480x600x70mm Active Cutting Area
 - 0.75kW 24000RPM Spindle with ER16 collet
 - 3 axis controlled by 4(2 for Y) NEMA 17 17HS4401 step motors & A4988 drivers
 - CNC Shield v3(for Arduino UNO) used for movement control & Arduino UNO with GRBL installed
